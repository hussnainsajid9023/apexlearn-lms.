private redis = Redis.fromEnv();
async execute<T>(fn: () => Promise<T>): Promise<T> {
const state = await this.getState();
if (state === 'OPEN') return this.fallback();
try { return await fn(); }
catch (e) { return await this.handleFailure(); }
}

Lecture Key Takeaways

In distributed systems, circuit breakers prevent cascade failures when downstream microservices degrade. Unlike in-memory circuit breakers, distributed systems require shared state counters (like Redis or Upstash) to synchronize health states across serverless workers.

State Transitions to Memorize: 1. Closed: Normal flow. Failures increment sliding error count. 2. Open: Trip threshold hit. All calls instantly routed to fallback. 3. Half-Open: After resetTimeout, allow trial request to verify downstream recovery.

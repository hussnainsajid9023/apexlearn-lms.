Dr. Elena Vance Instructor

Great question, Marcus! If you immediately reset to CLOSED, you trigger a classic thundering herd problem. Thousands of concurrent queued requests flood the fragile downstream service, causing immediate cascade failure. A single canary probe tests actual service health safely.

// State transition safety rule
if (canaryResponse.status === 200) { circuit.tripClosed(); // safe to resume 100% flow } else { circuit.tripOpen(); // back to quarantine for 30s }

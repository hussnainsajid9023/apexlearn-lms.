# ApexLearn LMS ⚡
### Enterprise Cloud & Distributed Systems Learning Management System

ApexLearn LMS is a multi-page interactive Learning Management System application built with Streamlit and styled using design references generated by Google Stitch. Every screen is implemented using native Streamlit widgets (`st.columns`, `st.metric`, `st.text_input`, `st.button`, `st.tabs`, `st.progress`, `st.radio`, `st.expander`, etc.) so all forms, buttons, timers, simulations, and code runners are fully interactive and functional.

---

## 💾 Data Persistence Architecture

All user accounts, course progress, quiz results, personal notes, and Q&A threads persist in a local JSON database:
- **Location:** `data/apexlearn_db.json`
- **Security:** Passwords are never stored in plaintext; they are hashed with `hashlib.sha256` using an application salt.
- **Persistence:** Submitting a quiz, saving notes, registering a user, or posting in the forum immediately saves to the JSON database.

## 📦 Installation & How to Run

### 1. Requirements
Ensure Python 3.10+ is installed on your system.

### 2. Install Dependencies
Install the required packages using pip:
```bash
pip install -r requirements.txt
```

### 3. Run the Application
Start the Streamlit application:
```bash
streamlit run app.py
```

The application will open automatically in your browser at `http://localhost:8501`.
